# Compiler projects

- [MLIR dataflow accelerator](mlir-dataflow/): compile a small transformer feed-forward block into a tiled hardware execution plan; explore fusion, SRAM capacity, placement, and communication with a numerical simulator.
- [LLVM backend register allocation](LLVM%20Backend%20Register%20Allocation%20Pass/): custom register allocation, traceable stack spilling, regression tests, and benchmarks.
- [GPU instruction scheduling simulator](GPU-Oriented%20Instruction%20Scheduling%20Simulator/): dependency-aware scheduling and modeled execution latency.
